# Smart Device Disconnect

## Overview
Smart Device Disconnect is a powerful web application that allows users to manage, monitor, and control the connection status of multiple smart devices across their network. This tool provides a clean, intuitive interface for IT administrators, smart home enthusiasts, and security-conscious users who need granular control over their connected devices.

## Features

### Device Management
- **Add Devices**: Easily register new smart devices to the monitoring system
- **Device Tracking**: View all connected devices in a comprehensive table format
- **Status Monitoring**: Real-time status indicators show whether devices are connected or disconnected
- **Filtering & Sorting**: Quickly find specific devices in your network

### Connection Control
- **Selective Disconnection**: Disconnect specific devices with a single click
- **Batch Operations**: Apply connection changes to multiple devices simultaneously
- **Reconnection Management**: Easily reconnect devices when needed
- **Scheduled Actions**: Set up timed disconnects and reconnects for security purposes

### Security Features
- **Unauthorized Access Prevention**: Identify and manage unknown devices on your network
- **Connection History**: Track when devices connect and disconnect
- **Network Monitoring**: Get a comprehensive view of all devices accessing your network

### User Interface
- **Clean Design**: Modern, intuitive interface with clear visual indicators
- **Responsive Layout**: Works seamlessly across desktop and mobile devices
- **Status Indicators**: Color-coded statuses (green for connected, red for disconnected)
- **JSON Output**: Export device data in JSON format for integration with other systems

## Technical Details
The application is built using modern web technologies including:
- **Frontend**: HTML, CSS, and JavaScript
- **Responsive Design**: Flexbox layout ensures proper display on various screen sizes
- **Data Management**: Efficient client-side data handling for device information
- **API Integration**: Connects to smart device APIs for real-time status updates and control

## Use Cases
- **Home Network Security**: Disconnect unknown or suspicious devices from your home network
- **Parental Controls**: Manage children's device access according to schedules or rules
- **IoT Management**: Control when IoT devices can connect to the internet
- **Network Troubleshooting**: Isolate devices by disconnecting them for diagnostic purposes
- **Privacy Control**: Limit when certain devices can access your network or the internet

## Getting Started
1. Clone the repository
2. Open the index.html file in your browser
3. Add your devices using the form at the top
4. Start managing your device connections

## Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Network admin privileges to control device connections
- API access to smart devices (for full functionality)
